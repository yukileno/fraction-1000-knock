# 熱血！分数1000本ノック 〜猛特訓編〜

小学5年生の算数単元「分数のたし算とひき算（通分・約分・帯分数）」を、熱血野球の1000本ノック形式で楽しくマスターできる学習Webアプリケーションです。  
Chromebookでの快適なキーボード操作、実質的な問題解答時間（スイング秒数）の精密計測、放置・他ページ離脱時のタイムストップ機能、端末内への回答ログ蓄積、そして**Googleスプレッドシートへの自動同期 ＆ 猛特訓記録分析**に対応しています。

- **公開URL**: https://yukileno.github.io/fraction-1000-knock/

---

## 🌟 主な特徴と仕様

### 1. 劇画風「星飛雄馬 vs 花形満」対決スタジアム
- 問題が進むとピッチャーから火の玉豪速球が飛来し、バッターの前で激震待機！
- 正解すると「カキーン！！」の快音とともに豪快フルスイングでスタンドインホームラン！
- 不正解時は空振りストライクで気合の再挑戦。

### 2. 精密な学習時間計測 ＆ タイムストップ仕様
- **1問ごとの実質解答時間（スイング秒数）を計測**:
  - 各問題で何秒かけて解いたかを内部で1秒単位で正確に記録。
- **他ページ閲覧・別アプリ移動時の即時タイムストップ**:
  - 別タブを開いたとき（`Page Visibility API`）、別ウィンドウや他アプリへ移動したとき（`window.blur`）に即座にタイマーが完全停止。
- **60秒無操作時の放置検知 ＆ タイム除外ロールバック**:
  - 60秒間操作がない場合は「タイム！休憩中」モーダルが表示されタイマーストップ。放置されていた直前の無操作時間（60秒）は解答時間からロールバック除外されるため、純粋な集中時間のみが記録されます。

### 3. シンプルで安全なログインフロー（パスワードなし）
- **毎回ログイン**:
  - アプリ起動時に「クラス」と「出席番号」を選択。
- **登録済みの場合**:
  - 「**〇〇選手ですね！合っていますか？**」とお名前が大きく表示され、「はい、グラウンドへ入る！」を押すだけで開始できます。
- **初回の場合**:
  - ニックネーム（背番号・名前）を入力して「入部登録してスタート！」を押すと、スプレッドシートの「児童名簿」へ自動登録されます。

### 4. スマート保存 ＆ スプレッドシート連携
- **1分おき自動保存 ＆ 打席記録**:
  - 児童の打撃記録（問題、解答、所要秒数、空振り回数など）が1分おきに先生のスプレッドシートへ自動送信されます。
- **手動保存ボタン**:
  - いつでも「☁️ 今すぐ保存」で即時送信可能。

### 5. 熱血！1000本ノック猛者番付（ランキング機能）
- **トップ画面（入部届）＆ 特訓中ヘッダーからいつでも閲覧可能**:
  - ログイン前のトップ画面、または特訓中の画面上部「🏆 猛者番付」からワンタップで番付を表示。
- **1000本ノックまでのカウントダウン ＆ 限界突破・追加特打ランキング**:
  - 1000問未満の児童：「**あと 〇〇問 (〇%)**」と目標達成までの残問数を表示。
  - 1000問完走の児童：「**🔥 完走！追加 +〇〇問**」と燃える猛者バッジを表示し、追加特打の球数でさらに上位を競います。
- **クラス別絞り込み ＆ 自分の順位ハイライト**:
  - 「全クラス合同」または「各クラス」での番付絞り込み、および自分の順位サマリーバナー・行ハイライトに対応。

### 6. 5問正解ごとのご褒美ミニゲーム（1球入魂バッティング）
- 前回のミニゲームから5問正解するたびに発動。ミニゲーム中はドリルの計測タイマーを停止します。
- 対戦投手は登録児童名簿からルーレットで選出され、その児童の正解数に応じて球速・能力が決まります。

### 7. スモールステップ出題（段階0〜8）と計測球
- 練習球は児童ごとの段階に合わせて出題します（`js/fraction.js` の `generateLeveledProblem`）。
  - 0: 同分母・答えが1より小さい（小4） / 1: 同分母・答えが1以上・帯分数（小4） / 2: 異分母・約分なし / 3: 異分母・約分あり / 4: 異分母・答えが1をこえる / 5: 帯分数・繰り上がり下がりなし・約分なし / 6: 帯分数・約分あり / 7: 帯分数・繰り上がり下がりあり / 8: ミックス（第1期と同じ出題）
  - 上がる: 同じ段階の直近5問のうち4問を「90秒未満で1発正解」。下がる: 3回以上ミス（または答え表示）が2問続く。時間がかかっても自力で解けた問題では下げない。
  - 最初の段階は通算の1発正解率から決定（40%未満→0、60%未満→2、75%未満か20問未満→5、それ以上→8、未経験→2）。段階は端末に児童ごとに保存。
- 計測球（研究用）: 出題10問に1問、全員共通の「帯分数の引き算・約分あり・繰り下がりなし」を出題し、段階の判定には使いません。
- 計測球は3回、練習球は5回ミスすると答えを表示して次へ進みます。答えを表示した問題は記録に残しますが、「1本」（累計問題数・ランキング・ミニゲームの5問）には数えません。
- `計算ドリル記録` の N列=出題段階、O列=種別（計測球/練習球）、P列=答え表示。

### 8. 教師用機能
- 出席番号45番（教師用）でログインすると、強制正解ボタン（F2キー）が表示されます。

## 🛠️ claspによる自動更新・管理体制

本プロジェクトは `clasp`（Google Apps Script CLI）と完全に紐付けられています。
GASの修正は `gas/Code.js` を編集し、`clasp push` の後、既存のデプロイIDを指定して `clasp deploy -i <デプロイID>` で更新します（Web アプリのURLを変えないため）。

- プロジェクトID: `1FUUYxQ-efy9LfQkHOLopO0qUEAWieT7w0fTVfFC0oPZzr5Zx-JWrD9CO`
- スプレッドシート内のシート構成:
  - `計算ドリル記録`: 児童の解答ログ（A:記録日時, B:クラス, C:出席番号, D:ニックネーム, E:問題式, F:演算, G:単元分類, H:正解, I:所要時間(秒), J:間違えた回数, K:セッションID, L:日付, M:ログID, N:出題段階, O:種別, P:答え表示）
    - M列のログIDは端末で採番される一意IDで、再送時の重複判定に使います（同じ問題を解き直した記録は重複扱いしません）。
  - `児童名簿`: 登録児童の一覧（最終更新日時, クラス, 出席番号, ニックネーム, 累計問題数などは自動計算式）
  - `日別集計`: 日付・クラス・時間帯（開始〜終了時刻）で絞り込んだ集計
  - `研究用_学習曲線`: 所要時間とミス回数の推移（左右2軸グラフ）
- スプレッドシートのメニュー「📐 分数ドリル管理」から、シート修復・名簿の再集計・重複ログ削除・集計シート再構築を実行できます。

### データ保存の安全策
- 端末は、GASが保存成功を返したログだけを「送信済み」にします。失敗・通信断のときは端末に残し、自動で再送します。
- GASの保存処理は `LockService` で直列化し、同時アクセスで行が上書きされるのを防いでいます。
- 端末内の送信済みログは7日分（最大2000件）だけ残し、それより古いものはスプレッドシートにのみ保存されます。未送信ログは消しません。

### 管理用API（URLからの調査・修復）
- `inspect_sheets` / `deduplicate_logs` などの管理用 action は、スクリプトプロパティ `ADMIN_TOKEN` を設定した場合のみ、`?action=...&token=<ADMIN_TOKEN>` で実行できます。未設定の間はすべて拒否されます（メニューからは実行可能）。
- 児童用アプリが使う `get_users`（名簿・成績の取得、ランキング用）はトークンなしで利用できます。
